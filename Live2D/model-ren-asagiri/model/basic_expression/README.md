## 実装内容

| パラメータ | 動作 |
|---|---|
| `ParamEyeLOpen` | キャラ左眼＝画面右の青目。0閉眼、1開眼 |
| `ParamEyeROpen` | キャラ右眼＝画面左の茶目。0閉眼、1開眼 |
| `ParamMouthOpenY` | 0閉口、1通常会話の最大開口 |

頭部は`art/head/parts`、首・衣装・四肢は`art/processing_v001/front/parts`の現行素材。元の41レイヤーをメッシュ化し、`art/expression_rig`から口5枚と閉眼移行用まつ毛2枚を追加した。元PNG48枚（補助素材7枚を含む）はハッシュ不変。元PSDも静止配置版として保持。

瞬きは白目を閉じ、虹彩を白目にクリッピングして隠す。虹彩の画像比率は変更しない。開眼のALTまつ毛と、閉じ際の専用まつ毛を切り替える。ALTまつ毛は開度0/0.5/1で不透明度0/100/100、閉眼用は0/0.25/0.5/1で100/100/0/0。途中で線が途切れないよう閉眼側の位置を調整。前髪・横髪・アホ毛の描画順を501とし、目の線が髪の前へ出ないようにした。

口は口内・上歯・舌・上下口縁を独立メッシュとして保持。開度0/0.1/1にキーを置き、閉じ線から開口へ移行する。歯と舌は口内へクリッピング。中開きでも上歯が見える。開口幅・高さは過去に了承された通常会話の控えめな範囲を基準に、現行の顔へ配置し直した。
