## 採用前または追加実装時に整える点

1. **Zの中立を確認する。** 講義のLesson 05ではZ=0時の回転を0°と記録しているが、現物は+1°。意図した微傾斜かを確認し、共通の中立として0°へ戻す場合は子の配置を保って前後比較する。今回変更なし。
2. **視線を追加する前にクリッピングを用意する。** 現在は左右虹彩、歯、舌のクリッピング参照が0件。現在の開閉は変形で収めているが、虹彩の平行移動や開口の追加拡張でははみ出しを別途防ぐ必要がある。以前の版には虹彩→白目、歯・舌→口内の参照があった。
3. **首・顎の連動と横髪・後ろ髪の揺れを補う。** 首PNG自体は最新だが4頂点・2三角形で静止。素材の不備ではなく実装範囲の差。首の襟側固定、頭側追従、口開閉に対する顎の小さな連動を別工程で作る。
4. **XY用の親子構造を決める。** 現在はRotation直下にFace_Warp、Mouth_Warp、Hair_Base_Warpが並列。Face_WarpだけにXYを作ると口・髪はその変形に追従しない。後で共通の頭部XY親を設けるか、各部へ同じ姿勢キーを持たせるかを決める。正面メッシュや既存表情を一括作り直す必要はない。
5. **管理名と参照先を整理する。** アホ毛のIDが汎用の `Param`、首のArtMesh IDが `ArtMesh`、上歯が `mouth_teeth_upper2`、Deformer名が `Hair_ahoge_Wrap` になっている。現時点の動作不良ではないが、再利用する際には役割が分かる名前へそろえる。教材PSDの記録参照は旧 `Lesson01_PSD_Import` のままで、現行の `Lesson_PSD_Import` と異なる。埋込画像は正常なため、再リンクだけのためにPSD再読込でリグを上書きしない。

補足：左目Meshの一部に反対側 `ParamEyeROpen` のキーも残る。大部分は同一フォームの複製で、左下まぶたの右目軸による座標差も最大約0.00000134（親内の局所座標）だった。GUIで右目だけを閉じた際に青い左目まで閉じる現象は見られなかった。不要な紐づけの整理候補であり、大きな左右誤連動と判断して修正を急がない。

顔下地は330頂点・570三角形だが、形状キーは中立1個。以前の失敗したXY終点を持ち込んだ状態ではない。眉・耳・目などの多くは4頂点で、親Warpが変形を担う構成。詳細な目尻などの局所形状を詰める時だけ対象Meshを検討し、一括再メッシュをしない。
