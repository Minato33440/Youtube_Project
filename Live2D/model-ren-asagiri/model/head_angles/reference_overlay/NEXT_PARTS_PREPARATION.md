# 次に抽出・補完する場合の範囲

2026-09-26。今回の既存メッシュによる実装を先に比較するための準備。下記は作画差を詰める候補で、原画から抽出済みの完成パーツではない。

比較元は `art/Looking_down/Looking_down (2).png`、配置は本フォルダーの `reference_overlay_manifest.json`。拡縮・平行移動だけの固定配置を使い、モデルを変更するたび原画を再フィットしない。右向きは幾何の反転を出発点にするが、左右の目の色・髪の描画を反転流用しない。

| 優先 | 候補 | 比較する箇所／抽出時の条件 |
|---|---|---|
| 1 | 顔下地の頬〜顎 | 耳の下から頬を通って顎先へ入る曲線。現行は短縮と位置合わせが改善したが、原画の頬の丸み・左右の面の広さまで一致していない。目鼻口を焼き込まず、顔下地と輪郭を一体で比較。隠れる側は耳・髪の下へ余白を補完する。 |
| 2 | 近い側の耳 | 原画で見える上端、頬との付け根、内側の陰影。現行耳は正面素材の変形なので、角度素材の内部形状までは再現しない。輪郭だけの問題なら既存耳の変形を優先し、内部の線が不足する場合に限り追加素材にする。 |
| 2 | 横髪・もみあげ | 耳根を隠す範囲、頬に掛かる毛先、顔を動かした際の重なり。前髪全体を差し替えず、左右の横髪のうち必要な束に限定。裏側・根元の隠れ面を補完する。 |
| 3 | 顎下の陰影 | 現在は首素材に描かれた影を使用。原画の影の斜め方向・幅は完全一致していない。顔下地／首の既存描画を分ける必要がある場合に影だけを補助レイヤー化。新しい顎裏の肌面は作らない。 |

原画は目の開き方、鼻・口の描画、頭髪のボリュームも正面採用絵と異なる。これを顔全体の差し替えで合わせると、Boss了承済みのキャラクターと瞬き・口開閉を変えてしまう。まず輪郭・耳根・髪の重なりで改善が足りない箇所を選び、限定した素材補完へ進める。

追加素材を用いる場合も、X=0の正面頷きと中立の完成PNGを基準に残す。終点の静止一致だけでなく、中間角度での輪郭の折れ・二重線、瞬き・開口時の接続を再検査する。
