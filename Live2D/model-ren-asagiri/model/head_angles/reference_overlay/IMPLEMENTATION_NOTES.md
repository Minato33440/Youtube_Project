# 傾きを残した原画による斜め頷き調整

2026-09-26。原画は `art/Looking_down/Looking_down (2).png`。拡縮と平行移動だけで合わせ、原画のロールを水平に戻さない。以前の回転正規化比較は今回の目標ではない。

## 編集内容

- `oblique_nod_reference_overlay.psd` を既存の `Ren_front.cmo3` に追加。左右2枚は下絵パーツ、描画順999、不透明度45%。パーツをロックして原画を固定。右向き用は形状比較のための反転で、完成モデルの虹彩色・髪の非対称は反転しない。
- `Head_Tilt > Head_Oblique_Roll_XY (Rotation2) > Head_XY` の階層に変更。AngleX/Yそれぞれ3キー。斜め下の左終点だけ-6度／右終点だけ+6度。他の7キーは0度。頭部全体と顔のパーツに原画の傾きを持たせる。
- `Face_Contour_XY (Warp10)` の既存5×5変換・4×4ベジェを使用。AngleX±30／Y-30の2キーで頬、鼻を含む顔下部、顎先を独立調整。顔全体を回転するだけで済ませず、耳下から頬・顎への形を短縮し、近側と遠側で横移動を分けた。新規PNGや顎裏描画は追加していない。
- `Mouth_Align_X (Warp12)` にAngleYの3キーを追加。左右斜め下だけ口の6ArtMesh全体を上方へ移動し、鼻・顎との位置関係を補正。口開閉パラメータの形は保持。
- 参照2枚は非表示に戻し、下絵を含めずSDK5.0で書き出し。アトラスは既存と同じ2048×2048一枚。
