## 採用範囲

Boss提供のLooking_down 3枚は部品位置の参考として使用し、完成PNGや描画内容は差し替えていない。(2)を正面頷き、(3)を画面左向き＋頷き、(1)を中間位置の参考にした。肩・襟・シャツ・胴体は固定し、頭部、耳、首上部のみを調整。逆向きは幾何関係を反転し、茶／青の虹彩や髪の固有の非対称は維持した。[参照位置レビュー](../../art/Looking_down/review/LANDMARK_REVIEW.md)の数値は相対位置の目安であり、厳密な角度計測値ではない。

前回モデルとruntime・確認動画はarchive/before_reference_fit_20260925に保持。head_neck_hairとbasic_expressionの既存モデルは変更していない。

## 実装

- **Head_XY (Warp8)**：AngleX/Y各-30/0/30の9状態。Y=-30で髪上部の移動を抑え、口・顎を下へ追従させて下顔面の圧縮を軽減。X±30では中央制御点の左右移動と遠い側の幅圧縮を追加。修正した単独軸から4隅を生成した。
- **Neck_XY (Warp9)**：Neck_Followの下、neck-clavicleの上に追加。首上端をY=-30で下へ、X±30で左右へ追従させ、襟に入る下部は固定。変換5×5／ベジェ2×2、XY9状態。
- **ear_L／ear_R**：AngleX3キーを追加。近い耳の露出を少し増やし、遠い耳を髪側へ寄せる。開眼・閉眼・口・髪の既存階層は保持。
- 既存のJaw_Open、Head_Tilt、Neck_Follow、5つの髪変形器と物理3グループは継続。

36.9%表示時の追加操作量（原画座標の実測値ではない）：Yの頭部上中央-10表示px／下中央+10、Xの中央±24、左右端は12〜15内側。首上中央はY+10／X±24、耳は近側6外側／遠側5内側。前回からの差分であり、この数値だけを別モデルへ転用しない。

## 動画と検証

実際にSDK5.0形式で書き出したmoc3を描画。動画は正面頷き0〜3秒、左向き＋頷き3〜6秒、右向き＋頷き6〜9秒、複合動作9〜12秒。各区間の境界は中立へ滑らかに戻る。前回の区間切替時の角度ジャンプも修正した。

48 ArtMesh／27パラメータ、変形器10個。元PNG128枚、今回追加確認した頭部・参照41枚、前工程cmo3、今回開始時のバックアップはハッシュ不変。正面中立・瞬き・会話口・髪端点は了承済み前工程との差が最大1/255。AngleZ+30は前工程に対して差8超が2画素あるが、今回開始時のhead_anglesとの比較では差8超0。16状態で下部シャツの描画差は最大1以下。

16静止状態と動画抜粋を目視し、小角度で耳根・顎下・首・襟の目立つ背景抜けを認めなかった。独立した静止画レビューでも前回からの改善を確認。正面頷きは控えめで、静止画では軽い縦伸長とも読める。強める場合は顔全体の下降を増やすより、瞼と髪の重なり等を個別調整する。

髪物理の設定ファイルは前回と同一。今回の緩やかな動画入力では休止状態からの物理出力が0だったため、別の強めのAngleZ診断入力でも比較した。3出力すべてが動き、前回との差は0。動画へ人工的な揺れを追加していない。XYに応じた髪揺れと緩やかな入力への感度調整は今回未実施。
