- **Mouth_Align_X (Warp12)**：Head_XYの下、閉口・上下口縁・口内・上歯・舌の6ArtMeshの上。変換5×5／ベジェ2×2、AngleX3キー。口の開閉形状を変えず、左右端点で口全体を顔の向きへ寄せて顎と整列。中立キーは無変形。36.9%表示で左8表示px／右7表示pxの全体移動を行ったが、この値は原画pxではない。
- **Neck_Shadow_X (Warp11)**：Neck_Follow → Neck_XY → Neck_Shadow_X → neck-clavicle。変換5×5／ベジェ4×4、AngleX3キー。既存の首の陰影を左右別に変形し、顎下から首への影の傾斜を姿勢へ合わせた。襟内の下部は固定。元の影は非対称なので補正量も左右同一にはしていない。
- **遠い側の耳**：前工程で既存AngleX端点の幅を控えめに圧縮。今回は耳と目・髪の配置を確認して保持。首のNeck_Shadow_Xも前工程から保持。
