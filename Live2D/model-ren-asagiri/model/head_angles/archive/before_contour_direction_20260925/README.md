## 今回の実装

- **Face_Contour_XY (Warp10)**：Head_XY → Jaw_Open → Face_Contour_XY → face_underfill。変換5×5／ベジェ4×4、AngleX/Y各3キー。遠い側の頬・下顎を内側へ寄せ、顎先を少し中央側へ戻す。斜め頷きの2隅では近い側と遠い側を別々に補正。X=0の全Yキーは無変形で、了承済みの正面頷きを保持する。
- **Neck_Shadow_X (Warp11)**：Neck_Follow → Neck_XY → Neck_Shadow_X → neck-clavicle。変換5×5／ベジェ4×4、AngleX3キー。既存の首の陰影を左右別に変形し、顎下から首への影の傾斜を姿勢へ合わせた。襟内の下部は固定。元の影は非対称なので補正量も左右同一にはしていない。
- **遠い側の耳**：既存AngleX端点で幅を控えめに圧縮。耳の内側の位置、近い側の耳、正面は保持。独立した目・鼻・髪の新規変形は追加せず、既存Head_XYによる遠近変形を継続。

今回の操作量と検査範囲は[test_report.md](test_report.md)を参照。以下は保持した前工程の実装。

## 保持した前工程

- **Head_XY (Warp8)**：AngleX/Y各-30/0/30の9状態。Y=-30で髪上部の移動を抑え、口・顎を下へ追従させて下顔面の圧縮を軽減。X±30では中央制御点の左右移動と遠い側の幅圧縮を追加。修正した単独軸から4隅を生成した。
- **Neck_XY (Warp9)**：Neck_Followの下、neck-clavicleの上に追加。首上端をY=-30で下へ、X±30で左右へ追従させ、襟に入る下部は固定。変換5×5／ベジェ2×2、XY9状態。
- **ear_L／ear_R**：AngleX3キーを追加。近い耳の露出を少し増やし、遠い耳を髪側へ寄せる。開眼・閉眼・口・髪の既存階層は保持。
- 既存のJaw_Open、Head_Tilt、Neck_Follow、5つの髪変形器と物理3グループは継続。

36.9%表示時の追加操作量（原画座標の実測値ではない）：Yの頭部上中央-10表示px／下中央+10、Xの中央±24、左右端は12〜15内側。首上中央はY+10／X±24、耳は近側6外側／遠側5内側。前回からの差分であり、この数値だけを別モデルへ転用しない。

## 動画と検証

実際にSDK5.0形式で書き出したmoc3を描画。動画は正面頷き0〜3秒、左向き＋頷き3〜6秒、右向き＋頷き6〜9秒、複合動作9〜12秒。各区間の境界は中立へ滑らかに戻る。前回の区間切替時の角度ジャンプも修正した。

48 ArtMesh／27パラメータ、変形器12個。元PNG128枚と頭部・参照41枚、前工程cmo3、開始時バックアップはハッシュ不変。正面頷きはX=0、Y=-30〜+30の3刻み21位置×通常／閉眼／会話口の63条件で比較し、最大差2/255、差8超の画素0。追加変形器に伴う微小な描画差のみで、目視でも形状を維持。正面中立・瞬き・会話口・髪端点は了承済みhead_neck_hairとの差が最大1/255。AngleZ+30の前工程との差8超2画素は今回以前からの差。16状態で下部シャツの描画差は最大1以下。

16静止状態、修正前後比較、動画抜粋を目視し、今回の小角度で耳根・顎下・首・襟の目立つ背景抜けを認めなかった。最終的な自然さはBossの確認待ち。正面頷きを強める変更は行っていない。

髪物理の設定ファイルは前回と同一。今回の緩やかな動画入力では休止状態からの物理出力が0だったため、別の強めのAngleZ診断入力でも比較した。3出力すべてが動き、前回との差は0。動画へ人工的な揺れを追加していない。XYに応じた髪揺れと緩やかな入力への感度調整は今回未実施。

Cubism Editor 5.3.04 FREEで保存・閉じる・再読込・書出しを実施。1枚2048アトラスは確認用。VTube Studio／nizima LIVE、完全横顔、大笑いの追加開口は未検証／未実装。
