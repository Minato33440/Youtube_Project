verify_preservation.pyの厳密な18条件検査は**不一致のまま記録**。正面中立／閉眼は表示最大差2/255、正面の頷き・口開閉では輪郭近辺に差が出た。1200×1800描画で正面15条件の最大差47/255、2/255超は最大154画素。他の未編集3姿勢は最大120/255・559画素。変更終点の身体側はRGBA差0。メッシュ再分割のため、前回の「全18状態表示一致」を今回へ転用しない。

追加のverify_refined_poses.pyで以下を描画し、親が比較画像を目視確認した。

- 正面Y=-30/-15/0/15/30×口0／0.7／1.0。修正前後のalpha>=16輪郭を双方向の画素距離で比較し、2000×3000で最大1px（元キャンバス換算2px）。厳密RGBA一致とは区別。
- 全パーツの正面Y=0/-30×口4段階を基準runtimeと比較。見た目に大きな表情・輪郭の変化は見られない。
- 反対側終点、同側の頷きなし／上向きは再分割の影響を別シートで比較。輪郭差はそれぞれ2000×3000で最大2／1／1px。今回これらのキーを直接調整していない。
