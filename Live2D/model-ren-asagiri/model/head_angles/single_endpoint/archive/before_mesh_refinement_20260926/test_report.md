## 実際のモデルからの静止描画

Cubism Editor 5.3.04 FREE、SDK5.0互換形式、既存2048アトラス1枚。全体runtimeは48 ArtMesh、顔下地だけのruntimeは1 ArtMesh。Pythonのlive2d.v3とCore 5.1による描画で、自動瞬き・呼吸を停止し、CoreのUpdateを直接呼んで物理演算を評価しない。

顔だけの2000×3000描画を原画の固定配置と比較。元原画の顔を候補として貼り付けたり、出力を後から変形したりしていない。比較シートは同一の切り取り領域と注釈だけを使用。

輪郭照合は原画の可視線を等間隔25点にして、各点からalpha>=16のモデル外縁までの最短距離を求めた。4000×6000座標換算：中央値5.384px、平均6.018px、最大19.020px。顎近傍3.702px。最初の試作で約22.97px残った画面右頬の該当点は、追加の頂点調整後11.679pxとなった。初回の結果は`contour_check/initial_contour_check`へ保持。

制約：これは一方向の25点距離で、輪郭全域の最大誤差ではない。ラスタ解像度とアルファの閾値にも依存する。髪に隠れた推定線、目・口・耳・髪、鼻の厳密な座標一致は自動合格していない。特に頬の角張りと画面左上端は目視の再調整候補。
