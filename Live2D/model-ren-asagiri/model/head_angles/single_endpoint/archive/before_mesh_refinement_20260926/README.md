## 今回の見方と残り

水色が原画から取った輪郭、赤がモデルのアルファ境界。桃色の十字は鼻・顎の目標点で、鼻の位置を自動採点した結果ではない。顔下地に既存の鼻・眼窩・頬の陰影が描かれているため、陰影の調整は輪郭と別に見る。

可視輪郭を25点で照合した最短距離は、4000×6000座標換算で中央値5.38px、平均6.02px、最大19.02px。最大差は画面左の髪際に近い頬上端。頬の一部には角張りが残り、耳下から髪に隠れる部分は推定線なので合格判定していない。今回の数値は輪郭を近づけるための目安であり、顔全体や動作の自然さの合格ではない。

正面5角度×通常・閉眼・会話口の15状態と、反対側終点・同側中立・同側上向きの3状態は、基準runtimeと表示一致。変更終点の身体側も一致した。確認は静止・物理演算停止の条件で、中間動作の保証ではない。
