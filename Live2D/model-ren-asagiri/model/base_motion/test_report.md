# Ren_base 初回基礎整理 — 検証記録

実施日: 2026-09-30

## 対象

入力はBossが補修済みの `Ren_deformer1.cmo3`。Cubism Editor 5.3.04 FREE上で複製先 `Ren_base.cmo3` を編集した。アホ毛の再制作はBossの担当として変更対象から外した。

## Editorで確認した内容

- 閉眼時の眼窩の赤みは入力版で改善していることを確認。
- 顔下地の傾き修正とは別に、回転デフォーマのZ=0には+1°が残っていたため0°に修正。
- 口開閉の閉・中間・開で顎追従を確認。大きな輪郭破綻は見られなかった。
- Zの両端で首の追従と襟との接続を確認。確認した表示範囲では明瞭な隙間は見られなかった。
- 横髪・後ろ髪の-1/+1を確認。振幅は小さく、確認した表示範囲では明瞭な隙間は見られなかった。
- 4グループの物理設定を読み込み、Editorのグループ一覧で確認して保存。

これらはEditor内の目視確認。全パラメータ組合せ、物理演算による連続動作、配信アプリでの動作、販売品質を保証するものではない。Bossの今回の変更に対する視覚的了承は未取得。

## 機械検査

CMO3は読み取り専用で構造を確認した。ファイル内部をコードで書き換えていない。

- [foundation_audit.json](foundation_audit.json): 中立Z、4件のクリッピング、頭部階層、顎キーを確認。46枚の使用画像RGBAと既存メッシュを保持。親付け替え後の中立座標差は最大0.00843程度。
- [hair_neck_checkpoint_audit.json](hair_neck_checkpoint_audit.json): 最終保存版は46 ArtMesh / 14 Deformer / 28 Parameter / 4物理グループ / アトラス0枚。新しい首・髪のキーと接続を確認。使用画像46枚のRGBAは入力と一致。メッシュ変更は首と後ろ髪の2枚のみ。
- 首は4頂点/2三角形から65頂点/103三角形へ、後ろ髪は4頂点/2三角形から52頂点/70三角形へ変更。外周の余白も変わるため、端点・中間の見た目は引き続き確認する。
- アトラス取り消し前の安全コピーと最終保存版を比較し、パラメータ、メッシュ形状・キー・親子構造、全デフォーマ、物理設定、レイヤー素材が一致することを確認。アトラス作成だけを取り消したことを保存ファイル上で検証した。
- 最終保存版: 7,121,388 bytes / SHA256 `26731bcdaef0b87277d9f25ab53979e0b7663f143821c50fef7bfc5a870fc5d2`。教材原本のSHA256も開始時と一致し、未変更を確認。

## テクスチャの扱い

検証用2048pxアトラスを一度作成したが、Bossの要望に従い取り消した。通常保存ではディスク上の更新が確認できなかったため、同じ本番作業ファイル名へ「名前を付けて保存」で保存し直した。取り消し前のコピーはローカルarchiveに保存済み。

本番アトラスはPro版導入後、4096pxを目安として後工程で検討する。今回はruntimeを書き出しておらず、GIF/MP4の新規納品もない。物理設定と検査コードの準備をruntime検証済みとは扱わない。

## 作業体制と効率

主担当がEditorを操作し、子Agent 1名が読み取り専用で入力・保存モデルの差分監査と検証コードの準備を担当。子AgentはGUI操作やCMO3変更を行っていない。実効モデル・推論強度、トークン消費、費用は本記録では確定できないため記載しない。

手戻り: 検証用アトラスを本体の調整段階で作成してしまい、Bossの方針を受けて取り消し・保存し直した。今後はEditor内の基礎動作確認を先に進め、アトラス作成を後工程として扱う。
