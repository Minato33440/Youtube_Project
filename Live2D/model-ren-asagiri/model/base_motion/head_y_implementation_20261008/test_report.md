## 追加した動き

全作成・確認で頭部X=0、Z=0。輪郭・目元を大きく変えない控えめな上下動とし、頭部と髪の変形、顔の縦方向の短縮と位置、首上端の追従を調整した。

| オブジェクト | ParamAngleYのキー | 役割 |
| --- | --- | --- |
| Head_XY_Base（既存） | -30 / 0 / +30 | 頭部・髪を含む全体の上下動と縦方向の変形 |
| Face_Warp（既存） | -30 / -15 / 0 / +15 / +30 | 顔中央と輪郭の相対的な変形 |
| Neck_Y_Follow（新規） | -30 / 0 / +30 | 首上端の追従。中間・下端と鎖骨側を固定 |

Face_Warpの±15は端点間の補間から明示的にキーを追加した中間形状で、別途手彫りした形状ではない。Head_XY_BaseとNeck_Y_Followの±15は補間表示で確認した。首用ワープは既存Neck_Followの子、neck-clavicleの親に挿入し、既存のZ親を保持した。
