## 決定済み

- Tommy’s Worksは「リサの地球観察室」と別事業。制作技術は共有する。
- 利用者の声・喋り方・用途をキャラクター設定で技術的に制限しない。穏やかな動作は推奨プリセットとする。
- 最初のレン試作は白シャツで「通常待機→聞き役→短い発話→微笑み」。
- VTube Studioとnizima LIVEを対応目標とし、各アプリで個別に設定・確認する。
- 本体を先行。衣装・トグルの別売りは候補、雨・濡れ差分は未決定。
