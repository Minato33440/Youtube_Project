# 朝霧レン：キャラクター・商品仕様

更新: 2026-09-19。構想と実装目標の整理。販売中の仕様ではない。

## 1. 事業と商品の位置付け

Tommy’s WorksのSFWを中心としたオリジナルキャラクター販売。YouTube「リサの地球観察室」とはブランド・販売導線を分ける。既存X `@TomTom3340` と新規SFW Pixivを展示窓口、BOOTHを販売先の第一候補とする。既存XのBL中心から、男の子・女の子・不思議な相棒などへ展開する構想。

価値の中心は、表情と控えめな仕草、導入して使えること。「沈黙の時間が魅力的」は展示の軸であり、購入者に短い発話・特定の声を強制する仕様ではない。

AIツール、加筆・編集、Live2D制作の実際の担当工程を明示する。プロフィールの公開状態、アカウント名の確定状況は今回監査していない。

## 3. 本体と試作

最初はデフォルトの白シャツ姿。本体を先に制作し、レンで30〜60秒の「通常待機→聞き役→短い発話→微笑み」を見せる。

| 要素 | 方針 |
| --- | --- |
| 服 | 白シャツ。グレーパンツは原案。袖丈・裾丈は未確定 |
| 表情 | 通常、聞き役、微笑みを最初に実装。考え中・照れ・驚き等は拡張候補 |
| 動き | 口の開閉・形状、瞬き、眉・視線、軽い首の動き、胸肩の呼吸、髪の揺れを段階的に検証 |
| 口パク | 母音を扱える口形状を目標に、アプリ入力と変形の対応を検証。形状の作成は製作者の仕事 |
| 可動範囲 | 最終商品の全身／上半身範囲は未決定。試作は顔〜胸肩を優先して評価 |
| 手 | 原案はポケットか下げた姿。手・指トラッキング、歩行は初版の対象外候補として維持 |
| アプリ | VTube Studio／nizima LIVE。まず手元のWindows環境で確認。両対応を検証前に広告しない |

首2〜3度・通常時に首を動かさない等の旧数値は原案の演出例であり、可動域の上限ではない。基本表情や自然な口パクは本体の価値として整え、追加料金前提で削らない。

## 5. 購入者への提供と更新

本体の配布候補：実行用モデル、テクスチャ、表情・物理・モーション、アプリ別設定、キー一覧、導入説明、利用条件、見本画像。編集用PSD/cmo3の販売・同梱は未決定。

- モデルの同じパラメータID・意味・範囲をできるだけ維持し、更新互換性を検証する。
- 衣装追加時はCubism編集を購入者に要求しない形を目指す。統合版配布／更新方式は試験後に決定する。
- 購入者の設定を常時回収する方式にはしない。購入者のPC内でバックアップ・保持・更新できる手順を作る。
- 既存の口パク感度・動き倍率・ホットキー・自作表情と、新衣装の設定の統合は別々に確認する。設定を丸ごと読み込めば全て統合されるとは保証しない。
- 推奨の穏やかな設定と、購入者が自分で調整する設定例を示す。用途や音声の好みを技術的に固定しない。

## 6. 価格・販路・公開前事項

- 白シャツ本体を手に取りやすい価格にし、着替えや追加トグルを別売りにする案を検討。金額は未決定。
- 8,800〜9,800円は旧夏セット一括案。旧事業提案の4,980円も別仕様の仮案であり、今回の本体価格ではない。
- BOOTHを第一候補。ココナラはAI由来作品の出品条件が課題として挙がっており、確定販路へ数えない。掲載前に現行公式条件を再確認する。
- nizimaの販売マーケットとnizima LIVEアプリは別。アプリ対応がマーケット出品可を意味しない。
- 非独占の汎用モデルとしての販売、収益化、再配布、名前変更等を利用条件で具体化する。旧Grokの販売文を完成済み規約として流用しない。
- 実モデルの動作録画とイメージ動画を区別する。販売数、市場規模、導入成功率の根拠はまだない。
