Bossの `ALT_mouth_interior.png` の切り出し時点の実寸239×187を維持した。4000×6000原画へ換算する目的の拡大はしていない。上下口縁は、唇を新規に描いたものではなく元の輪郭の分離。上中央には元から明瞭な口縁線がないため、上側の輪郭パーツは左右の口角が主になる。下の白い帯は下歯として扱わず、元の口縁表現として保持した。

歯・舌の裏は元の口内から採色したRGB(100,47,44)で補った。口内背景に歯や舌の線は残っていない。外周の矩形状の余りを局所的な曲線マスクで整理したため、再合成は元絵とのピクセル完全一致を目的としない。元の色と形を基準にした分離素材。舌端の色にじみ、白い口縁の太さ、歯端の形はBossの仕上げ対象。動作用の口形・パラメータや全身への本配置は未実施。

今回の5枚を使う際は、従来の `ALT_mouth_*` 一式を重ねて表示しない。旧素材は比較用として保存してある。

## 首・襟・裏地の確認

参照は `neck-clavicle.png`（20:11更新版）、`collar_L.png`、`collar_R.png`、`shirt_inside.png`。正確な参照内容は `source_snapshot/` と `validation.json` のSHA-256で固定。

- 顎の黒いV字線は除かれ、首の上方と鎖骨・胸元への肌の延長を確認した。
- 左右襟はRGBA合成で確認し、内側の肌が透明になっている。個別ファイル表示時の見え方に基づく当初の「肌が残る」という指摘は撤回する。
- `shirt_inside.png` は襟の裏に置く素材として使える。上下に十分な布があり、見せる範囲は前面の襟・首・シャツで調整する。
- **仮配置では胸元の肌の下端が襟のV字の開きより上で終わり、裏地の灰色が途中から見える。肌を下へ約100〜120px延長する余地がある。** これは仮配置基準の目安。まず最終配置を合わせ、その開口部全体と隠れる余白まで肌を延ばす。
- 首左右端の細い髪色・襟色に見える帯は拡大して再確認する。首そのものの輪郭線まで一律に消さない。
- 襟と旧シャツ胴体には仮配置で隙間・ずれが見える。切り出し寸法も変わっているため、本配置を合わせてから不足部分の描き足し量を判断する。

`neck_collar_review.jpg` は単独パーツと積層、`neck_extension_review.png` は胸元の延長候補。座標は `neck_review_placements.json` に診断用として記載している。保持されたテクスチャを旧PSDに照合した推定値であり、全身manifestへは適用していない。裏地座標は手動の仮置き。シャツ胴体は旧PSDを参照し、最新首・襟との差を見るための合成。
