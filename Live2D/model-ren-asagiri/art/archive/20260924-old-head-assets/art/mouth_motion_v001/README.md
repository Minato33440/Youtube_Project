## 使用素材と処理

- 顔：`processing_v001/front/parts/face_underfill.png`。輪郭外清掃済み、SHA256 `f7d8727b5b2bfa2816bd4d21148cedba14ee1b6676058836b2a979d070dc07a0`。
- 閉口：同フォルダ `mouth_closed.png` の9/22 09:12更新版。
- 歯：同フォルダ `ALT_mouth_teeth_upper.png` の9/22 08:19更新版。古い分離歯の代わりに使用。口素材座標で幅212へ縦横比を保って調整し(13,3)へ配置。
- 上下口縁：`mouth_split_v002/parts/mouth_rim_upper.png`／`mouth_rim_lower.png` の09:39／09:38更新版。
- 口内・舌：同フォルダ `mouth_cavity.png`／`mouth_tongue.png`。

切り詰められた口縁は、上を(0,0)、下を(16,96)として登録。幅は閉口から大開口へ連続変化。開口素材基準に対し大開口の横倍率0.78、縦倍率0.68で顔に収めた。縁の線幅が途中で薄くなりすぎないよう、線と形状の変形量を分けている。
歯は縦につぶさず口に隠れる範囲を調整。小開口で歯端が牙のように見えないよう左右の露出も絞った。舌は下側へ追従し、小開口で口いっぱいに出ないよう奥へ隠した。開口量0〜0.12で閉じ口線と開口線を移行する。

状態別PNGでは口内の形で歯と舌を透過化済み。元の全パーツは `source_snapshot/` に保持している。Cubism本実装では元パーツからマスク・変形キーを組む。状態別の切り抜きを完全な動作用素材として扱わない。

## 確認結果・仕上げ候補

- 閉口では口内・歯・舌・上下開口縁の可視画素0。二重の開口線が残らない。
- 小開口で歯と舌が口全体を占める初回案を修正。中間形を一覧で目視確認。
- 上下口縁の接続部分の色・太さの差、閉じ際に細かく見える線の濃淡は残る仕上げ候補。画像の拡大で見える色むらも素材由来のため、今回一律の塗り直しはしていない。
- 顔の角度変形、顎の連動、笑顔以外の口形、発音別形状、音声同期は未設定。
- 元PNG、既存全身PSD／manifest／cmo3は変更していない。元の分離PSDも更新していない。

## 検証と再開

各PSDのag-psd読み戻しで層名・配置・表示・RGBA一致。独立psd-tools再描画では白／灰背景の最大チャンネル差1.50/255未満、2/255超の画素0。詳細は各状態の `psd_verification.json` と `independent_verification.json`。
使用7PNGは作業後もハッシュ一致。`validation.json` に素材パス・ハッシュ・サイズ・配置・状態別可視画素数を保存。
今回は親Agentのみ、子Agent0。推論強度の実効値、消費量、厳密な所要時間は未計測。初回の小開口で歯・舌の露出過多を認め、クリッピングと追従位置を修正して再確認した。

手修正後はこのフォルダの `build_mouth.py` を再実行しない（出力を上書きする）。以後の変更は別版で実施する。次工程はBossによる動きの確認を反映し、最新の顔・首襟・髪・耳・目・口を全身PSDに統合、その後Cubismに反映する。
