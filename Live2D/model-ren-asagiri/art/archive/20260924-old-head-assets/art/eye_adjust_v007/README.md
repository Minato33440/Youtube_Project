## 今回の変更

1. 採用済みALT虹彩の幅88pxは維持し、高さを112→92pxに調整。色・放射模様・ハイライトは保持した。
2. 上まつ毛は指定ALTを維持。原画のまぶたとの位置関係を見ながら、R=(1750,765)、L=(2058,762)へ移し、虹彩上側にかかるようにした。白目の開口も上線に追従させ、下縁は原画の形を目安に合わせた。虹彩はR=(1818,776)、L=(2105,773)。
3. 白目の角ばった輪郭を開口マスクで整え、縦長・見開き気味の印象を抑えた。下縁の指定点は滑らかにつないでいる。
4. 下まぶたは原画の白目と肌の境目を細い帯として切り出した。元のRGBを保持し、帯の端を透過でなじませた。**独立した濃い黒線ではなく、白い縁と肌色を少し含む淡い素材**。必要ならBossが縁の幅・肌へのなじみを修正できる。参照用の周辺画像も保存した。
5. 確定眉はUpper_eyelid_left/rightを眉として使用。従来の上瞼線は旧試作内の別素材を維持し、新眉と混同していない。

原画と完全に同じ目の描写にはしていない。ALTの虹彩模様と目尻表現を維持しつつ、比率と見える範囲を寄せた試作。細かな光沢の違いは残る。
