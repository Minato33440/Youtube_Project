# Looking_down 参照ランドマークレビュー

2026-09-25。`Looking_down (1).png` を比較元、`Looking_down (2).png` を正面うなずき、`Looking_down (3).png` を画面左向き＋うなずきの位置参照として確認した。参照画像は**部品位置と相対移動だけ**に使い、現行レンの目の大きさ、輪郭、髪型、線、色、表情は `art/head/preview/head_sample.png` を維持する。元PNG、PSD、Cubismモデルは変更していない。

## 基準

- `H`：アホ毛を除いた髪の実体上端（solid crown）から顎先までの高さ。
- `C`：左右の耳／こめかみの中点。キャンバス原点ではなく頭蓋側の基準。
- 比較時は各画像を `H` で正規化し、まず `C` と上首の支点を合わせる。全身の画面内移動、拡大率、肩の向きは除外する。
- 方向は画面基準。`(3)` は鼻先が画面左へ向く。逆向きキーは、虹彩色の左右を入れ替えずに水平反転した位置関係を使う。

## 現行うなずきの診断

`case_00.png` と `case_02.png` の同一模様を局所照合すると、現行 Y=-30 はおおよそ crown `+0.03H`、eyes `+0.035H`、nose `+0.025H`、mouth `+0.02H`、chin `ほぼ0`、ears `+0.02H`（下向きを正）だった。これは厳密な解剖計測ではなく、420×570プレビュー上の画像移動量である。

目の下降量そのものは参照に近い。一方、顎が固定され、口も目より少なくしか下がらないため、下顔面が縦につぶれ、頭部全体がデフォーマ内で圧縮された印象になる。`(1)→(2)` では solid crown がほぼ留まる一方、目・口・顎は揃って約 `0.02〜0.03H` 下へ進む。したがって、目をさらに下げるより口と顎の追従不足を直すのが先。

## 正面うなずき Y=-30 の目標

neutral からの下向き移動量。単独キーでは左右差を増やさない。

| ランドマーク | 目標移動 | 実装意図 |
| --- | ---: | --- |
| solid crown | `0〜+0.005H` | 頭全体の縦スライドを避け、髪殻を基準にする |
| 両目の平均線 | `+0.025〜+0.035H` | 現行量はほぼ適正。両眼を同量にする |
| 鼻 | `+0.020〜+0.030H` | 目との距離を急に伸縮させない |
| 口 | `+0.020〜+0.030H` | 現行より追従を増やす。口だけ顔から浮かせない |
| 顎先 | `+0.015〜+0.025H` | 上へ寄せない。下顔面の潰れを防ぐ |
| 耳の中点 | `0〜+0.015H` | 耳〜上首を回転支点にし、顔より移動を抑える |

目安として H=350px 表示なら、目 `9〜12px`、鼻・口 `7〜11px`、顎 `5〜9px` 下。これは画面ズームではなく Head_XY 内の相対変形とする。肩・胴体・襟とカメラ尺度は固定し、首上端だけを無理なくつなぐ。

顔の縦関係は、neutral の固有比率を保ったまま小さく変える。eye→nose、nose→mouth、mouth→chin のいずれか一段だけを `0.015H` 以上縮めない。特に chin を neutral より上へ置くと、参照と逆になり、現行の圧縮感が強まる。

## 画面左向き＋うなずき `(3)` の目標

まず上記の Y 変形を作り、その上に X 変形を加える。`(2)→(3)` の全身移動と縮尺を除くと、主変化は中心線の横移動、眼間の短縮、片耳の露出である。

| 関係 | 目標 |
| --- | --- |
| 鼻の中心 | 頭蓋中心 C から画面左へ `0.07〜0.11H` |
| 口の中心 | 画面左へ `0.05〜0.08H`。鼻より小さく、同方向 |
| 顎先 | 画面左へ `0.03〜0.06H`。鼻→口→顎の中心線を折らない |
| 眼間距離 | neutral の `0.80〜0.90`。両目を同じ距離だけ動かさない |
| 近い側の青目（画面右） | 大きさを概ね維持し、顔中心へ軽く寄せる |
| 遠い側の茶目（画面左） | 横幅を neutral の `0.80〜0.90` 程度へ抑え、鼻側へ寄せる |
| 画面右の耳 | 露出を増やし、目線付近の高さを保つ |
| 画面左の耳 | 髪・輪郭側へ隠し、左右同時に同量露出させない |
| 髪殻 | 画面右の後頭部量を保ち、画面左を圧縮。前髪だけを横滑りさせない |

`(3)` では遠い茶目が近い青目より数百分の一H低く見え、眼線がわずかに斜めだが、画像には小さなロールと作画差も含まれる。純粋な AngleX に強い傾きを固定せず、X+Y の組合せキーで弱く出す。逆向きでは、茶目／青目の色レイヤーを交換せず、近眼・遠眼の役割だけを反転する。

## 避ける欠陥

- crown、顔、耳、顎を同量移動するだけの縦スライド／横スライド。
- 顎を固定または上へ押し、目だけ下げて下顔面をつぶす変形。
- 横向きでも眼間・両眼サイズ・両耳露出が neutral のままの平面せん断。
- 鼻だけが横へ飛び、口・顎の中心線が折れる状態。
- 近い頬を細くし、遠い頬を広げる逆遠近。画面左向きでは画面右側が近側。
- 顔輪郭と髪が逆方向へ動いて、こめかみ、耳周囲、顎下に透明な隙間が出る状態。
- 頭だけ下げて首が襟へ刺さる、または肩まで動いてカメラ移動に見える状態。
- `(3)` の画面移動、肩の向き、細い頬の黒点、目の形・大きさ、線や塗りを原画仕様として複製すること。

## 受入確認

1. neutral と Y=-30 を同じ表示倍率で重ね、solid crown がほぼ留まり、eyes→mouth→chin が連続して下へ追従する。
2. X±30 は左右反転した位置関係になり、近眼と遠眼の役割、耳露出、眼間短縮が反転する。虹彩色の左右は固定。
3. X±30/Y=-30 の四隅で、鼻・口・顎の中心線、こめかみ、耳周囲、顎下、首と襟に裂けや二重線がない。
4. 連続再生で、Y は縦スライド、X は一枚板のせん断に見えない。最終判断は静止画の数値一致ではなく、Bossの目視確認とする。

## 不確実性

3枚は同じキャンバス条件・同一リグの厳密なキー出力ではなく、`(3)` は頭部だけでなく胴体、構図、軽いロールも変わる。上の値は小角度〜中角度の初回調整帯であり、解剖学的角度の実測値ではない。参照と現行素材は目・輪郭の作画比率が異なるため、絶対位置へ合わせず、neutral からの相対移動だけを採用する。
