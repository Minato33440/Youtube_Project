## 検証と次工程

41層の名称・座標・表示・RGBAは書き出し前後で一致。ag-psdとpsd-toolsの2系統で読み戻した。全6000行を分割してレイヤーから再描画し、最大表示差1.683/255未満、差2超の画素0。顎下の不透明重なり18465px、胸元の検査範囲5170pxは全域を首パーツが覆っている。入力41PNGのハッシュ不変。

今回は通常開眼・閉口の静止PSD。口内5PNG・閉眼移行用上まつ毛2PNGはhead/expression_sourcesに保持し、まだPSDに入れていない。次の工程で最新顔へ合わせて追加する。Cubismへの読み込み、メッシュ作成、まばたき、開口、首と顎の連動、髪の揺れは未実施。販売用完成モデルや動作保証の登録ではない。

`prepare.py`は元PNGから配置・確認画像を作る。PSDは既存の共有PNG→PSD書出処理を利用。`verify.py`は独立読戻しを行う。PSDを手編集した後は上書き再生成しない。元PNG変更は先に確認し、現行PSDをarchiveへ退避して更新する。
