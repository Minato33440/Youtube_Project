## 発語の間と呼吸

- 休止全体の目標：読点0.12秒、通常文末0.50秒、問いかけ・意味上の大きな区切り0.70秒。既存の間へこの値を足すという意味ではない。今回、話題転換のみを独立に試験したわけではない。
- 文中に合成された余分な休止は、意味の区切りと確認できた場合に限り読点相当とする。無声子音や促音を「無音」として削らない。
- 短い読点で吸気しない。文末休止の終わり寄りで約0.36秒吸気、発語中は緩やかに呼気。30fpsの今回の実装では11フレーム＝約0.367秒の吸気。
- 吸気終了は休止終端の50ms以上前、開始は休止開始の30ms以上後。値の上昇は吸気、下降は呼気。両端の速度が0になる三次補間を使用。
- 冒頭は既に吸った状態、最後は呼気後の値で静止。長い無発語区間の周期呼吸や、休止のない長文での息継ぎ追加は未検証で、別途設計する。

呼吸値の0.18〜0.593756、呼気速度係数0.11/秒、1区間の最大減少0.36は今回のリサで得た人間型の調整開始値。身体の実測呼吸量ではない。形状の違うモデルで同じ数値が同じ見た目になるとは扱わない。

## 人間型モデルへ展開する手順

1. 音声を合成し、句読点と実音声の区切りを確認して間を確定する。エンジンごとの前後無音や句読点処理を確認し、二重に休止を追加しない。
2. 確定音声に口・目・首・呼吸を同期。異なる文章には今回の絶対時刻を流用しない。まばたきは文の区切りを候補とし、休止短縮に巻き込んで動作時間まで縮めない。
3. 標準パラメータIDと増減方向を合わせ、原画・メッシュ・デフォーマをモデルごとに較正する。口の閉じ、すぼめ、首傾斜、胸肩とニット内部の動きを個別に確認する。
4. 10〜20秒程度の音声付き試作で、同期・破綻・自然さを確認。共通設定を上書きせず、変更点をキャラクター別補正へ残す。

リサでは全身・頸部が上下する呼吸は不自然との評価を受けた。胸の膨らみと肩、服の内部の皺へ動きを集め、顔・襟上端・外形・ベルトを安定させた判断を引き継ぐ。頂点座標やピクセル変位、画面配置の倍率はリサ固有なので一律適用しない。
