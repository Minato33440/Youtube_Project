## 1. 一言で何か

情感のある18歳男子の汎用Live2D。
文系気質で、喋りは落ち着いている。黙っている時間も、表情が動くので画面が死なない。
配信（VTube Studio / nizima LIVE）と、nizima LIVEのAIアシスタント常駐の両方を想定する。

見た目の中性は絵で分かる。商品の主語は中性ではなく、沈黙の表情と短い喋り。
特化の濡れモデル単体では出さない。濡れはトグル。

## 2. キャラクター

| 項目 | 内容 |
|---|---|
| 名前 | 朝霧 レン（あさぎり れん） |
| 年齢設定 | 18歳 |
| 見た目の基準 | セッション添付の2枚目寄り（壁際・汗ばんだ青年）。輪郭と肩はそちら。目は琥珀〜赤茶で情感を残す |
| 性格の核 | 文系男子。言葉を選ぶ。落ち着いて短く話す。黙っている時間がきれい。考え中に視線が外れる |
| 売りの特徴 | 喋っているときより、聞いているときの顔が本体。無言でも眉・視線・呼吸で飽きさせない |

年齢表現の注意:
- 顔を幼くしすぎない。1枚目の庭サンプルは情感は良いが16〜17に見えやすい
- 公開用は2枚目の骨格＋1枚目の目の温度
- 乾きデフォルトの透けは弱くする。濡れトグルでのみ強くする
- 中性は売り正面に出さない。男に読める骨格を残す

### 2-2. 設定の薄さ（購入者／LLM／制作で分ける）

以前の「本と画集が好きな夜間コース想定。雨のあと声が小さくなる、程度で十分」は、loreを増やさないためのメモだった。抽象すぎたので、用途別に直す。

購入者向け（商品に出してよい一文）:
- 本と画集が好きなくらいの文系
- 雨のあと、少し声が小さくなる

LLM／お供向け（プロンプトに渡す種。これ以上足さない）:
- 返事は短い
- 間を置いてから話す
- 相手が話しているあいだは、聞き役の顔のまま待つ
- 雨の話題のあとだけ、声を一段小さくしてよい
- 夜間コース、家族、トラウマ、成績の話は作らない

制作メモ（商品文に出さない）:
- 昼間の高校ドラマにはしない
- 眼鏡・本・カーディガンを記号として足して「文系」を説明しない
- 性格の癖は「雨のあと声が小さくなる」の一つで止める

## 3. 1stプロダクト（夏セット）

SKU仮称: **朝霧レン 夏セット**

含まれるもの: 白シャツ＋グレーパンツ、白タンク＋紺ショーツ、アームカバー、濡れトグル、立ち絵PNG、VTS / nizima LIVE対応。価格目安 8,800〜9,800円。
初版に入れない: 紺ブレザー、セーター、手・指トラッキング、VBridger細口、全身歩行。
手はポケットか下げの固定。

## 4. 冬パック

紺ブレザー＋白シャツ（デフォルトはネクタイなし）、ネクタイON、ベストON、セーター＋チノパン。夏の白シャツの首と袖は今から分けて描く。

## 5. 販路

Boothが主戦場。Xは15秒録画。nizimaマーケットはAI原画禁止、アプリ利用は可。PixivはSFW新規アカで立ち絵とGIF。「中性的」はタイトル先頭に置かない。

## 6. 表情・キー

1 シャツ / 2 タンク / A アーム / W 濡れ
Q 通常（呼吸とまばたきのみ） / E 小笑い / R 照れ / F 青ざめ / G 考え中 / H 聞き役 / Z 驚き小 / X 眠げ / C 汗

### 6-2. 無言時の微動作

Hのとき: 呼吸、不定期の眉、首を2〜3度内側へ、毛先の弱い物理。
Qには首の傾きを足さない。5度以上は出さない。同じ周期で全部を動かさない。
実装順: 呼吸 → 眉 → 毛先 → 最後に首。

## 9. 宣伝

完成Live2Dの画面録画15秒。可能なら聞き役3秒を入れる。Wan仮動画はイメージと明記。

## 10. 商品文案

タイトル: `【Live2D】朝霧レン 夏セット　黙っていても画面が死なない文系男子【VTS / nizima LIVE】`

X: 文系男子。喋りは短い。無言の顔が、残る。

### 10-3. 本文

朝霧レン。18歳の文系男子。言葉を選んで短く話す。
21色のカスタムではなく、まばたきと視線と聞いている眉に時間をかけている。
黙っている時間が長い人ほど使いやすい。

表情: 大きく口を開けて笑う差分はない。相手が話しているあいだは呼吸と眉が動く。聞き役では首が2〜3度傾き、毛先が弱く揺れる。通常の黙り顔には首の傾きは入れない。

Voice: 低め〜中低音、息多め、早口にしない。返事は短く、間を怖がらない。常用はQとH。nizima LIVEでは長い独白より短い返事。

体裁: 白シャツ＋グレーパンツ / 白タンク＋紺ショーツ / アーム / 濡れ
注意: 汎用、R18主目的はご遠慮、手トラッキングなし、冬服は別売予定。
