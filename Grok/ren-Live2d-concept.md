## 1. 一言で何か

情感のある18歳男子の汎用Live2D。
文系気質で、喋りは落ち着いている。黙っている時間も、表情が動くので画面が死なない。
配信（VTube Studio / nizima LIVE）と、nizima LIVEのAIアシスタント常駐の両方を想定する。

見た目の中性は絵で分かる。商品の主語は中性ではなく、沈黙の表情と短い喋り。
特化の濡れモデル単体では出さない。濡れはトグル。

## 2. キャラクター

| 項目 | 内容 |
|---|---|
| 名前 | 朝霧 レン（あさぎり れん） |
| 年齢設定 | 18歳 |
| 見た目の基準 | セッション添付の2枚目寄り（壁際・汗ばんだ青年）。輪郭と肩はそちら。目は琥珀〜赤茶で情感を残す |
| 性格の核 | 文系男子。言葉を選ぶ。落ち着いて短く話す。黙っている時間がきれい。考え中に視線が外れる |
| 売りの特徴 | 喋っているときより、聞いているときの顔が本体。無言でも眉・視線・呼吸で飽きさせない |

年齢表現の注意:
- 顔を幼くしすぎない。1枚目の庭サンプルは情感は良いが16〜17に見えやすい
- 公開用は2枚目の骨格＋1枚目の目の温度
- 乾きデフォルトの透けは弱くする。濡れトグルでのみ強くする
- 中性は売り正面に出さない。男に読める骨格を残す

### 2-2. 設定の薄さ（購入者／LLM／制作で分ける）

以前の「本と画集が好きな夜間コース想定。雨のあと声が小さくなる、程度で十分」は、loreを増やさないためのメモだった。抽象すぎたので、用途別に直す。

購入者向け（商品に出してよい一文）:
- 本と画集が好きなくらいの文系
- 雨のあと、少し声が小さくなる

LLM／お供向け（プロンプトに渡す種。これ以上足さない）:
- 返事は短い
- 間を置いてから話す
- 相手が話しているあいだは、聞き役の顔のまま待つ
- 雨の話題のあとだけ、声を一段小さくしてよい
- 夜間コース、家族、トラウマ、成績の話は作らない

制作メモ（商品文に出さない）:
- 昼間の高校ドラマにはしない
- 眼鏡・本・カーディガンを記号として足して「文系」を説明しない
- 性格の癖は「雨のあと声が小さくなる」の一つで止める
