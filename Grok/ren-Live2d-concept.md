## 1. 一言で何か

情感のある18歳男子の汎用Live2D。
文系気質で、喋りは落ち着いている。黙っている時間も、表情が動くので画面が死なない。
配信（VTube Studio / nizima LIVE）と、nizima LIVEのAIアシスタント常駐の両方を想定する。

特化の濡れモデル単体では出さない。濡れはトグル。

## 2. キャラクター

| 項目 | 内容 |
|---|---|
| 名前 | 朝霧 レン（あさぎり れん） |
| 年齢設定 | 18歳 |
| 見た目の基準 | セッション添付の2枚目寄り（壁際・汗ばんだ青年）。輪郭と肩はそちら。目は琥珀〜赤茶で情感を残す |
| 性格の核 | 文系男子。言葉を選ぶ。落ち着いて短く話す。黙っている時間がきれい。考え中に視線が外れる |
| 設定メモ | 本と画集が好きな夜間コース想定。雨のあと声が小さくなる、程度で十分 |
| 売りの特徴 | 喋っているときより、聞いているときの顔が本体。無言でも眉・視線・呼吸で飽きさせない |

年齢表現の注意:
- 顔を幼くしすぎない。1枚目の庭サンプルは情感は良いが16〜17に見えやすい
- 公開用は2枚目の骨格＋1枚目の目の温度
- 乾きデフォルトの透けは弱くする。濡れトグルでのみ強くする

## 3. 1stプロダクト（夏セット）

SKU仮称: **朝霧レン 夏セット**

### 含まれるもの

1. デフォルト衣装: 白シャツ＋グレーパンツ（半袖想定、上2つ開きで可）
2. サブ衣装: 白タンク＋紺ショーツ
3. トグル: アームカバー ON/OFF（タンク時）
4. トグル: 濡れ ON/OFF（タンク優先。シャツ側は髪と生地が重くなる程度）
5. 立ち絵PNG（セット特典）: 夏の夕立／濡れ雰囲気
6. 書き出し: VTube Studio / nizima LIVE 両対応

### 価格目安（未確定）

- セット: 8,800〜9,800円
- モデルのみを分けるならセットより少し安くしない

### 売らない／初回に入れないもの

- 紺ブレザー、ネクタイ、ベスト
- セーター＋チノパン
- 手の開閉トラッキング、指トラッキング（後述）
- 靴の履き替え
- VBridger必須の細口
- 全身歩行

### 手の扱い（2026-09-18判断）

初版では、指トラッキングと手の開閉トラッキングは入れない。

理由:
- レンの売りは顔と沈黙の表情。手は画面下部で、購入理由になりにくい
- 指まで分けるとメッシュと物理が増え、夏セットの完成が遅れる
- お供用途では手はほぼ動かさない。ポケット／下げた固定の方が安定する

入れてよい妥協:
- 手ポーズを1つに固定（ポケットか下げ、どちらか）
- 余裕があれば「ポケット ⇄ 下げ」の表示切替だけ。トラッキングではない

指トラッキングは、反応を見て無料更新か冬パックで足す。

## 5. ポジションと販路

### 狙う需要

- 個人勢の可愛い系／中性寄りの男性VTuber
- nizima LIVE AIアシスタント用の「話し相手の男の子」
- 配信の部屋に置ける日常着の男子
- 文系・落ち着いた声色の配信者

### 売らない戦い方

- 髪21色カスタム競争には入らない
- 「役職名」（執事・社畜・ゲーマー）より情感で取る
- 濡れ単体商品にしない

### 販路

| 場所 | 扱い |
|---|---|
| Booth | 主戦場。モデル販売 |
| X `@TomTom3340` | 完成モデルの画面録画15秒 |
| nizima マーケット | AI原画ポリシーで出品不可。アプリでの利用は可 |
| Pixiv | SFW専用の新規アカウントで、各キャラ立ち絵とSample GIFを投稿する。販売導線はBoothへ |
| ココナラ | 今は既製品より後回し |

### Pixiv運用（2026-09-18更新）

- 旧アカは使わない。SFW専用の新規アカ
- 投稿するもの: 各キャラの立ち絵、Live2Dを動かしたSample GIF／うごイラ
- 置かないもの: 濡れの強い透け、フォトリアル寄りの顔、R18
- フォトリアル判定で止まった経緯があるので、線と塗りはアニメ寄りを維持する
- GIFは「完成Live2Dの画面録画」を優先。Wan仮動画をPixivに上げる場合はイメージと明記

### nizimaの切り分け（重要）

- nizimaマーケット出品: 画像生成AI原画およびそれをLive2D化した作品は禁止。判定ツールあり
- nizima LIVEアプリ: 自作の `.model3.json` をローカル読み込みすればAIアシスタントで使える
- 商品文には「nizima LIVEのAIアシスタントで使用可能」と書いてよい。マーケット出品とは別

## 6. 表情とキーバインド案

数字キー＝衣装、文字キー＝状態、残りの文字＝表情。

### 衣装・状態

| キー | 内容 | 条件 |
|---|---|---|
| 1 | 白シャツ＋グレーパンツ | デフォルト |
| 2 | 白タンク＋紺ショーツ | |
| A | アームカバー ON/OFF | タンク時のみ |
| W | 濡れ ON/OFF | 主にタンク。シャツ時は弱い |

冬パック追加時:

| キー | 内容 |
|---|---|
| 3 | ブレザー |
| T | ネクタイ ON/OFF |
| V（衣装枠が空くなら別キー） | ベスト ON/OFF |

### 表情

無言時に画面が死なないよう、Q / H / G の3枚を特に丁寧に作る。

| キー | 名前 | 出し方 |
|---|---|---|
| Q | 通常 | 口角わずかに下がる。文系の黙り顔 |
| E | 小笑い | 口は大きく開けない。目が細くなる |
| R | 照れ | 視線が外れる＋頬 |
| F | 青ざめ | 血色ダウン |
| G | 考え中 | 視線斜め下、まばたき遅め |
| H | 聞き役 | AIお供の主表情。わずかに眉が動く |
| Z | 驚き（小） | 目を見開くだけ |
| X | 眠げ | ハイライト弱め |
| C | 汗 | 濡れとは別。緊張用 |
| 別キー | ハイライト消し | 落ち込み |

よく使うのは Q と H。大きな口開け笑顔は作らない。

### 常時パラメータ

- 目開閉、視線XY
- 口開閉（あいうえおまで。VBridgerは後回し可）
- 眉（困り／通常）
- 頭XYZ
- 呼吸の上下
- 髪物理（濡れONで減衰を強く、揺れを短く）

## 7. 夏セット パーツ分け

PSD仮ファイル名: `ren_summer_v1.psd`

### 大グループ

```
00_face
01_hair
02_body
03_outfit_shirt
04_outfit_tank
05_armcover
06_wet
07_fx
```

原則:
- 顔と体は1体。服は重ねる
- 濡れは別キャラを作らない。表示切替＋物理変更
- 手は初回、ポケット／下げた固定ポーズで可。指は分けない

### 00_face

輪郭（耳は別）、耳L/R、首、目白L/R、瞳L/R、ハイライトL/R、上まつ毛、下まつ毛、まぶた肌、眉L/R、鼻、口_閉、口_開、歯、舌、頬赤。

### 01_hair

前髪_中 / 前髪_L / 前髪_R、横髪L/R、後ろ髪_上 / 中 / 下、アホ毛。
濡れ用に「濡れ前髪_中」を1枚あると楽。

### 02_body

胸〜腹、鎖骨、肩L/R、上腕L/R、前腕L/R、手L/R、脚L/R。
乾きデフォルトでは胸部の処理はほぼ消す。
手は塊で描く。指の関節分割は初版しない。

### 03_outfit_shirt（デフォルト）

襟、シャツ胴、前立て／ボタン、袖L/R、裾、グレーパンツ。
襟と袖は冬ブレザー用に独立させて描く。

### 04_outfit_tank

タンク本体、肩紐L/R、裾、透け_弱、透け_強、ショーツ、紐。

### 05_armcover

カバーL/R。タンク時のみ。

### 06_wet

濡れ前髪_中、滴_頬、滴_鎖骨、滴_腕、服の濡れ乗算レイヤー。
Cubism 5.3のブレンドモード（オーバーレイ／乗算）向き。オフスクリーンは顔まわりに限定。負荷に注意。

### 描く順番

1. 顔＋髪
2. 体（タンクが見える範囲）
3. タンク＋ショーツ＋アーム
4. 白シャツ＋グレーパンツ
5. 濡れ
6. 耳・首のクリップ調整

### 初回チェック

- 全衣装で首の穴が空いていない
- 前髪が眉を削っていない
- シャツ⇄タンクで肩位置がズレていない
- 書き出しテクスチャは8192以下（nizima LIVE制約）

## 8. nizima LIVE への入れ方（利用者向けに後でREADME化）

1. Cubism: ファイル → 組み込み用ファイル書き出し → moc3
2. 物理演算も書き出す
3. テクスチャ8192以下
4. nizima LIVE → モデル一覧 → ＋ → `モデル名.model3.json`
5. 選択して「変更」
6. AIアシスタントとして使う場合は、モデル一覧のAIアシスタントタブで指定
7. 同じフォルダに `ico_xxx.png` があると一覧が見やすい

## 10. 商品ページ文案（Booth向け下書き）

価格未確定。公開前に数字とキー一覧だけ最終確認する。
売り文の順番は「空気 → 使い道 → 中身 → 注意」。仕様一覧から始めない。

### 10-1. 商品タイトル案

採用例:

`【Live2D】朝霧レン 夏セット　黙っていても画面が死なない文系男子【VTS / nizima LIVE】`

代案:

- `【汎用Live2D】朝霧レン｜白シャツ＆タンク＆濡れ差分　配信・AIお供向け`
- `朝霧レン｜18歳。落ち着いて話す。無言の顔がきれいな男子モデル`

### 10-2. キャッチ候補

短い（X・サムネ向き）:

- 黙っている時間がきれい、夏の男の子。
- 文系男子。喋りは短い。無言の顔が、残る。

少し説明を足す（Booth冒頭向き）:

文系男子で、喋りは落ち着いている。
無言のときも、視線と眉が動くので画面が飽きない。

配信の相手にも、部屋のAIお供にも。
白シャツとタンク、夕立の濡れまで、一体で切り替える夏の男子。

採用の軸:
- 「21色」ではなく「沈黙の表情」
- 「文系／落ち着いた喋り」は声と運用の想像を先に渡す
- 濡れは先頭に出さない
