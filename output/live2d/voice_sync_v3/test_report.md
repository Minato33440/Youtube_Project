## 実装

Cubism Editor 5.3.04 FREEで、Head_Tilt_Zの子にワープデフォーマ `Mouth_Form`（ID `Warp3`）を追加。表示に使う `Mouth_Interior`、`Mouth_LipLower`、`Mouth_Closed` をその子に設定。未使用で非表示の `Mouth_LipUpper` は変更対象外。

既存の標準パラメーター `ParamMouthForm` に -1 / 0 / +1 の3キーを作成した。ここでは表情の笑顔・不機嫌軸ではなく、発話用の横幅・丸め軸として使用する。

| 値 | このモデルの変形 |
| --- | --- |
| -1 | 横幅を約7割に絞り、縦方向を広げ、左右の口角付近を下げて丸みを付ける |
| 0 | 既存の口形状を維持 |
| +1 | 横幅を約1.17倍に広げ、高さを少し抑える |

倍率はGUI編集の概算。正確な形は保存したcmo3/moc3を参照する。新しい原画の生成や口テクスチャの差し替えは行っていない。

`ParamMouthOpenY` は承認済み v2 の全478値をそのまま使用。口形状の母音目標は a=0、e=+0.35、i=+0.9、u=-0.72、o=-1。通常の子音では前後の母音形状を補間し、閉唇音や休止では中立へ戻す。日本語の「う」を強い英語の oo と同じ形に固定しない設計。これは発話演出用の近似ルールであり、実写から測定した口形状ではない。

他モデルに適用するときは、OpenYとFormに対応する変形をそのモデルで調整する。表情制御が同じParamMouthFormを使う場合は上書き競合を解決する必要がある。開閉値は音量だけで駆動せず、今回の音素整列と補間済みカーブを使う。

## 検証

`verify_outputs.py` → `verification.json`。親が検査内容を確認し、口ROIを狭め、元音声PCMとMotion3時刻の一致検査を追加したうえで再実行した。

- 3本とも 1280×720、30fps、478フレーム、15.933333秒。FFmpeg全体デコード成功、音声・映像の開始時刻一致。
- 抽出PCMは元動画のデコード音声と完全一致。MP4音声はゼロオフセット相関 0.999983〜0.999986。
- v2のOpenYと478値すべて完全一致。Motion3の2曲線の値・時刻はCSVと一致。
- 新版の全478枚で、変化した画素は x=354〜402、y=201〜218 の口元内。目・首・体の変化なし。
- Form=0の OpenY=0 / .3 / .6 / .9 は、旧版の対応画像と画素差0。
- OpenY=0は103フレーム。閉じた唇にも幅の移行があるため、全てを同一画像には固定していない。
- Form範囲 -0.999957〜+0.899567、末尾10フレームは中立。
- Cubism編集用cmo3を保存・閉じる・再読込し、Form=-1/+1とOpenY=.6を組み合わせた変形をGUIで確認。最後に中立へ戻した。

目視では `shape_calibration.png` の15組（OpenY=0/.3/.6/.9/1 × Form=-1/0/+1）、`sequence_review.png` の0.5秒間隔と末尾、完成MP4から抜き出した配置版・比較版の画像を確認した。閉鎖時の穴、唇の分離、顔や首の巻き込み、配置版の文字との重なりはこの範囲で見当たらない。画像による開口分類は自動検査では実施していない。

音声の内容・声質は承認済みv2と同じものを維持し、上記のPCMと時刻検査を実施。親によるv3動画の音声付き通し試聴は未実施のため、技術検査合格と自然さの最終評価を分ける。Motion3ファイルのCubismアニメーションへのインポート再生も未検証で、確認MP4はCSVを実行用モデルへ直接適用して描画したもの。

## 再生成

作業フォルダはリポジトリルート。Pythonは `output/live2d/runtime_venv/Scripts/python.exe` を使用。

1. `output/live2d/voice_sync_v3/build_mouth_form_curve.py` で既存v2から2軸カーブを作る。
2. Cubismで形状を変更した場合は編集モデルを保存し、SDK 5.0形式で再エクスポートする。ルートに出力された実行用ファイル一式を `model/` にコピーして同期する。
3. `output/live2d/voice_sync_v3/render_model.py --calibrate` で形状検査画像を描画。
4. `output/live2d/voice_sync_v3/render_model.py` で478枚を描画。
5. `output/live2d/voice_sync_v3/compose_video.py` で3本を合成。
6. `output/live2d/voice_sync_v3/verify_outputs.py` で検査。

実行環境: Python 3.13、live2d-py 0.7.0.4 / Cubism Core 5.1、Pygame / OpenGL、FFmpeg。既存環境との互換性のためSDK 5.0形式を選択した。
