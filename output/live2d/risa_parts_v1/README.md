# リサ Live2D用パーツ原画 v1

2026-09-13。正面原画を元に、ChatGPT Imagesでパーツを生成・描き足し、23レイヤーのPSDへ配置した試作です。元の絵を画素単位で切り出したものではなく、顔、髪、服の細部には生成による差があります。

## 成果物

- `Risa_Live2D_Parts_v1.psd`: 編集用レイヤーPSD、RGB 8bit、1106×1422。
- `Risa_Live2D_Parts_v1_import_check.cmo3`: Cubism FREE 5.3.04への読み込み確認用モデル。リギングは未実施。
- `Risa_Live2D_Parts_v1.png`: 同じ配置の透過合成画像。
- `Risa_Live2D_Parts_v1_preview.png`: 明るい背景に重ねた確認画像。
- `parts_contact_sheet.png`: 元の生成パーツを並べた一覧。各枠で表示倍率が異なります。
- `parts/`: PSDと同じ大きさに調整した個別透過PNG。配置座標はmanifest参照。
- `generated/`: 採用した高解像度生成素材。追加調整の元データ。
- `manifest.json`: レイヤー順、表示状態、位置、生成素材と切り出し範囲。
- `generation_prompts.json`: 使用したプロンプトと元の生成ファイルの対応。
- `psd_verification.json`: PSD保存・読戻しの技術検査。
- `independent_psd_verification.json` / `test_report.md`: 独立したPSD検査とCubism実機確認の記録。

## 分割内容

|区分|レイヤー数|内容|
|---|---:|---|
|髪|2|後ろ髪／前髪・横髪・髪飾り|
|顔・首|2|顔の肌と鼻／首|
|耳|2|左右の耳。画面左は初期状態で非表示|
|目・眉|10|左右それぞれ白目、瞳、上まぶた、下まぶた、眉|
|口|4|閉じ口、口内、上唇、下唇。開口用3素材は初期非表示|
|身体|3|衣服と胴体／左右の袖・腕・手|

左右はすべて画面から見た方向です。瞳は完全な円を残し、白目を基準とするクリッピングを設定しています。

## 描き足した部分

前髪の下の額と頭部、顔で隠れる後ろ髪、襟に入る首、髪の下の襟元、袖の後ろのジャケット本体、腕の肩側の重なり、まぶたの下の瞳上部、開口時の口内を生成しました。隠れていた部分の形は推定です。

## 今回の制作範囲

基本のまばたき・視線・口パク・小さな頭の傾き・呼吸を作り始めるための原画です。髪の細い束、指、袖と手、ジャケットとパンツはそれぞれ独立させていません。大きな顔向きや腕の曲げ伸ばしは追加分割・描画調整が必要です。

PSDの分割と、Cubismでのリギングは別工程です。メッシュの精密化、デフォーマ、キー形状、口の閉じ形状、まばたき時の潰れ、視線のマスク、物理演算、SDK書き出しは未実施です。口の4素材を同時表示して完成口として使う設計ではなく、閉じ口と開口用素材をリギングで切り替え・調整します。

顔つきの同一性、肩の接続、目の開き方、透明な縁の細かな残りを拡大・変形時に確認してください。今回の静止画で見えない問題まで検証済みとはしません。

## 再生成

`prepare_parts.js` は生成済み素材の矩形切り出しと配置サイズ調整のみを行います。描き足し・背景除去はChatGPT Imagesで実行しています。
`tools/build_psd.js manifest.json` でPSDを再作成できます。Nodeの依存導入は `tools/package.json` を参照。実行環境のsharpへの絶対パスは各スクリプトに記録しています。

参考: [Live2D公式 PSDのインポート](https://docs.live2d.com/cubism-editor-manual/psd-import/)。非表示のPSDレイヤーも読み込まれる仕様です。
