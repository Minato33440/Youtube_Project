## ネイティブリグ

v3の `Chest_Local_Breath`（Warp4、8×9、Body_Clothesのみを配下に持つ）、全体伸縮を停止した `Breath_Base` は維持。新規デフォーマは追加せず、`Body_Clothes` アートメッシュにParamBreath=0/1の2キーを追加した。0は元の形状、1は以下の6頂点を移動した形状。

## 検証

`calibration_verification.json` はv3/v4に同一の呼吸0/0.3/0.6/1を入力し、さらに最大呼吸＋口0.958・すぼめ-0.55・首±8.4の姿勢を比較した。呼吸0ではv3/v4の描画が一致。最大呼吸で新たに変化した範囲はモデル画像座標(232,385)〜(503,829)で、上下ニットの領域に収まる。

`local_motion_verification.json` の結果（1080px確認動画と同じ描画倍率）:

| 対象 | 計測結果 |
| --- | ---: |
| 上部の皺・v3同一呼吸値に対する追加変位 | 下へ約4px、左へ約1px |
| 下部の皺・v3同一呼吸値に対する追加変位 | 上へ約3px、左右0px |
| 襟上端の呼吸0→1の移動 | 上下・左右0px |
| 胸中央の呼吸0→1の上下移動 | 0px |
| 左右肩の上昇 | 各16px（v3を維持） |
| 胸位置の白い生地の横幅 | 269→282px（v3を維持） |
| ベルト以下のv3との最大画素差 | 0 |
| 呼吸のみ変更した顔領域の最大画素差 | 0 |
| 襟上端の平均画素差 | 約0.00393 / 255 |
| 衣服内部に生じた透過の穴 | 全6姿勢で0 |

変位はテンプレート照合による局所推定であり、立体的な前後距離の計測ではない。皺の伸縮と陰影の移動による見かけの前後感を狙う。上記は最大呼吸値1での結果で、ナレーションは最大約0.594、呼吸のみ版は0.15〜0.85。実際の動画の振幅は最大域より小さい。

透過検査は中立姿勢の不透明領域を31px侵食したうちy>=350が対象。動く輪郭付近の全画素を保証するものではない。襟内部の変形で首の肌が上下したり、ベルトが浮き沈みしたりする構造にはしていない。口・首と同時に動かした極端姿勢にも内部穴はなかった。

動画検査は `verification.json` で合格。両MP4の全フレームのデコード、1080×1080/30fps/指定フレーム数、各7フレームの描画参照との照合を通過した。音声相関0.9999816、相関ピークのずれ0ms。呼吸のみ動画の0秒→2秒で、上部ニットの平均画素差7.73/255、下部6.05/255を検出した。ループ始終の平均画素差は0.226/255。SDK再生値の最大誤差は0.001247未満（許容0.003）で、`render_verification.json` に保存。入力・出力のSHA-256は `manifest.json`。

最大吸気の透過画像、`preview.jpg`、`breath_sequence_review.jpg` を目視し、襟・肩・ニット・ベルトのつながりを確認した。原画の皺が変形する様子と固定した部分は確認できるが、自然さの通し視聴は機械検査の合格と区別し、Bossの評価待ちとする。
