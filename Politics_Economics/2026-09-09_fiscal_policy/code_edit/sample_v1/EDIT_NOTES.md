# Sample MP4 v1 — 構成確認版

2026-09-10。今回の成果物はコード処理で生成する構成確認用MP4。音声・字幕・カード・元動画時刻を別ファイルに保持する。Filmoraでの演出調整と新しい編集プロジェクト作成は、構成のすり合わせ後の工程。

## 構成

冒頭抜粋 → 導入ナレーション → 国債・財政への不安 → 借換えの補足 → ネット資金需要の解説 → 減税財源への橋渡し → 投資と暮らし → 家計支援への橋渡し → 本編最後 → まとめ。

- 既存7区間を再編集。C01/C02/C05は内部を短縮し、C03/C06/C07は応答・文末・条件を残すため当初候補より広く採用。
- C03：元動画795.24–955.45秒を連続使用。途中の問いと条件を保持。
- C06：858.12–984.90秒。価格が下がる条件への応答の末尾まで採用。
- C07：1086.16–1149.16秒を連続使用。途中の文脈を保持。
- ネット資金需要は原典4区間、約3分55秒。2025-11-05公開動画の当時の説明として表示。
- −5％は会田氏の政策運営上の目安として紹介。ネットゼロを「企業と政府の支出が一切ない」とは言い換えない。輸入物価などの条件は本編と補足に残す。
- ナレーションは5本、合計約1分44秒。映像カードに全文字幕を表示し、文ごとに合成したWAVの実測尺で字幕を合わせる。
- チャンネル紹介は内容未確定のため未挿入。
- 冒頭の抜粋は後続C01の一部と重複する。引きとしての長さ・重複感は今回の視聴で判断する。

## 音声設定

楽町音穏_T3モデル、ノーマル、style ID `135718976`。ローカルAivisSpeech APIで生成。

| 項目 | 値 |
| --- | --- |
| 話速 | 1.17 |
| 感情表現の強さ | 1.00 |
| テンポの緩急 | 1.15 |
| 音高 | 0.00 |
| 音量 | 1.00 |
| 開始無音 | 0.12秒 |
| 終了無音 | 0.15秒 |

ユーザーが承認した最終スクリーンショットを採用。古い `default.aisp` の音高0.05・開始無音0.10秒は使わない。人名は合成入力のみ「あいだたくじ」「あいだ」に置換し、画面上の漢字を保持。

音声クレジット：Tαkoe:AivisSpeech:楽町音穏（T3モデル）

## 再編集・再生成

以下のパスはこの企画フォルダーを基準とする。

- 完成MP4：`exports/Sample-MP4_v1.mp4`
- 構成仕様：`code_edit/sample_v1_spec.json`
- 全体時刻・原典IN/OUT：`code_edit/sample_v1/timeline.csv`
- ナレーション原稿：`speech/sample_v1/narration.md`
- 結合前のナレーション：`speech/sample_v1/N01.wav`〜`N05.wav`
- 文単位の音声・API query：`speech/sample_v1/Nxx_yy.wav` と同名JSON
- 設定・生成音声の測定：`speech/sample_v1/generation_manifest.json`
- カード画像：`media/sample_v1/cards/`
- ナレーション別字幕：`subtitles/sample_v1/` のSRT/ASS
- 元動画：`media/sources/`
- 書き出し中間素材：`media/sample_v1/rendered/`
- 検査：`code_edit/sample_v1/render_manifest.json`、`qa_results.json`、`test_report.md`

リポジトリ直下の `work/prepare_sample_v1.py` で原稿・カード・字幕・仕様を生成し、`work/render_sample_v1.py` で映像を書き出す。`work/verify_sample_v1.py` は完成MP4と原音声の配置照合・確認フレーム抽出を行う。準備にはPillow、追加検査にはNumPy/Pillowを使う。

元動画の既存字幕は映像内に残る。新規ナレーション字幕・カードの原素材は分離して保存している。中間MKVや統合MP4の字幕・見出しは焼き込みのため、Filmoraへ移す際は元動画・WAV・SRT・カード・CSVを使って再構成する。
