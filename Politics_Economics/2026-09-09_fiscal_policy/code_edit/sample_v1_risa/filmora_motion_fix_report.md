# Filmora試作・静止不具合修正（2026-09-15）

Bossの確認で、インポート素材は正常なのにタイムライン上のモデル・切り抜き動画が静止していたことが判明。前回の「技術検査合格」は動きの検査が欠けていたため不十分だった。旧判定JSONにも訂正を追記した。

## 原因と修正

`work/build_risa_filmora.py` が動画クリップの `speed` 情報を除去していた。Filmoraは保存時に `offsetEnd=0`、速度カーブの `_totalTime=0` として補完し、素材の先頭フレームを保持した。音声クリップは独立して進行していたため、音声の相関検査と動画デコードだけでは検出できなかった。

映像7クリップ（切り抜き5・背景1・Live2D1）に、開始から素材尺まで1倍速のカーブを設定。Filmoraは読み込み・保存時にMD5を自動生成し、正しい終了時刻を保持した。変形・配置・素材・音声は引き継いでいる。

修正版をFilmoraで別名保存し、再読み込み後に再生・MP4書き出しを実施した。

- 修正版プロジェクト：`../../filmora/Risa_Layered_Trial_20260915_MotionFixed.wfp`
- 修正版MP4：`../../exports/Risa_Layered_Trial_20260915_MotionFixed.mp4`
- Bossの確認中に開いていた状態の保管：`../../filmora/Risa_Trial_BossCheck_BeforeMotionFix.wfp`
- 元の試作WFP・MP4および全編完成版は保持。

## 検証

- 修正前：切り抜き5区間とLive2D1区間の全6区間で静止を定量再現。
- 修正後：各区間の10%、30%、50%、70%、90%位置、計30フレームについて元素材との対応と時間差分を確認し、全6区間合格。
- Live2Dの時間差分はモデル領域内の共通不透明画素だけを使用。字幕や背景の変化では合格できない。モデルの時間差分平均は元素材0.004894、修正版0.006694、修正前0.00000858（正規化画素差）。
- 保存後の7つの映像再生範囲がすべて素材尺と一致。
- 1920×1080、30fps、4745フレーム、158.166秒を維持。全編デコードエラーなし。
- 音声6区間とも16kHz照合でピーク相関のずれ0ms、相関0.9924以上。
- Filmoraのタイムライン再生で切り抜き映像の変化を観察。書き出したMP4の代表フレームでモデル合成・字幕の進行・カット表示を確認。

検査スクリプトは `work/verify_filmora_motion.py` と `work/verify_filmora_trial.py --stem Risa_Layered_Trial_20260915_MotionFixed`。後者は動き検査の合格と有効な時間マップを必須条件とする。結果は `motion_checks/Risa_Layered_Trial_20260915_MotionFixed.motion_check.json` と `Risa_Layered_Trial_20260915_MotionFixed_verification.json`。

この検査はサンプル位置での静止・素材対応を検証するもので、全フレームの視聴判定や自然さの最終評価を代替しない。Bossによる修正版の通し視聴は未実施。
