- 全区間の直前・表示中・末尾・直後のフレーム検査: `boundary_verification.json`。
- 5区間の配置・文字との重なり確認: `narration_contact_sheet.jpg`。
- 再生成: リポジトリルートから `python work/render_risa_final.py`。

映像・音声の機械検査と代表フレームの目視確認を実施。全編の内容・視聴感について人間による再判定を済ませたという意味ではない。
