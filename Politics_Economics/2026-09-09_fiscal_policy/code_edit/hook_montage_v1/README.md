2026-09-10。Bossから「現行の冒頭は良い箇所を選んでいる。参考動画のように注目部分を短く重ねた冒頭だけを、別版として作る」と依頼。

## 成果物と比較元

- 新規出力：`exports/Opening-montage_v1.mp4`。20.565秒、1920×1080、30fps、H.264/AAC。5つの抜粋を連続配置した冒頭のみ。
- 比較元：`exports/Sample-MP4_v1.mp4`。16分31秒版はそのまま保持。旧冒頭は21.433秒の連続抜粋。
- 元版のSHA-256：`5d85bdf43ee52dcb0f5f7610be7c1a31365c53133f19a4189ab5a3f3eea51f64`。処理前後で一致を確認。
- 元版の構成仕様とタイムラインを `baseline_sample_v1_spec.json`、`baseline_timeline.csv` に複製。元動画IN/OUT、Bossの感想、ハッシュを `baseline_record.json` に記録。
- 本編への差し替え・新規ナレーション生成は行っていない。採用する場合は元版の冒頭21.433秒を置き換え、その後に既存N01をつなぐ。

総尺を大幅に縮める版ではなく、ほぼ同じ約20秒の中で3つの論点を先に見せる比較案。話者はいずれも会田卓司氏。別の日の発言なので、各カット上部に出典と公開日を表示する。

カットは直接切り替え。税収の条件と結論をつなぐ部分では約3％の画角変化を付けた。大きな字幕は逐語の引用ではなく、画面に「発言の要点」と示した編集上の要約。重要語を金色で強調し、元版の紺色と合わせた。新規BGM・効果音は追加していない。

## 参考動画の確認範囲

[Boss提示の参考動画](https://www.youtube.com/watch?v=4nR3dvrMdB0)。ブラウザーで0秒・10秒・20秒の静止画と自動字幕を確認。冒頭約31秒が複数の発言抜粋で、その後に本編が始まる構成。大きな縁取り字幕と彩度を抑えた画面が見える。映像や第三者の編集音声そのものは今回の素材に使用していない。参考動画の音声聴取・連続再生によるテンポ評価は未実施。

## カット境界の確認

既存YouTube自動字幕の発言単位が長かったため、ローカルのfaster-whisper smallでも周辺52秒を再認識して単語時刻を推定した。結果は `source_word_timings.json`。日本語の誤認識があるため、認識文をそのまま字幕にせず、元の字幕・前後の文脈と併せて編集判断に利用した。

完成版もローカルで再認識し、予定した発言と順序が含まれることを照合した（`output_asr.json`）。これは人による試聴の代わりではない。文末・助詞・息継ぎの自然さは視聴時に確認する。

## 検査・作業配分

- FFprobeで映像617フレーム、音声あり、総尺を照合。全編デコード合格。
- 5区間すべてで元動画と完成版の音声波形を照合。各区間の開始0.3秒後から1.5秒を比較し、相関係数0.989以上、時間差1ミリ秒未満。詳細は `audio_placement_qa.json`。
- 各カットとM01後半の6画面を抽出し、見出し・大字幕・文字切れ・強調色を確認。`contact_sheet.jpg` と個別PNGを保存。
- 試聴、通し視聴による自然さ、視聴維持効果は未確認。
- 子Agentは0体。親Astraが選定、実装、検査。実効推論強度・使用量・正確な工程別時間は未取得。
- ローカルASR用にプロジェクトの `.venv` へ `faster-whisper 1.2.1` と依存を追加。既存キャッシュのsmallモデルを再利用。クラウドへ動画・音声を送信していない。
- 最初の書き出しでFFmpegの小数表記を修正。画面確認後、要点字幕を拡大・強調して再検査。
